## Откуда веса и что с лицензией

Начальные веса: SigLIP 2 B/16 от Google (`open_clip` `ViT-B-16-SigLIP2`, тег `webli`), лицензия Apache-2.0.
Модель дообучена на данных кейса, учителем была наша SigLIP 2 SO400M. SO400M в свою очередь дообучалась на
VERI-Wild, а этот набор открыт только для некоммерческого использования. Поэтому и эти веса можно
использовать только некоммерчески; для коммерческого внедрения модель нужно переобучить без VERI-Wild или
получить лицензию у авторов набора.
